# Laravel Automate

Laravel Automation Steps - Automate your Laravel project setup with simple button clicks.

## Installation
```bash
composer require devoashim/automate
```

## Usage

After installation, visit:
```
http://your-app.test/auto
```

Click the buttons to run Laravel commands automatically!

## Requirements

- PHP ^8.0
- Laravel ^9.0|^10.0|^11.0
